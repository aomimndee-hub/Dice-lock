# Dice Lock — Extension สำหรับ Owlbear Rodeo

เครื่องทอยลูกเต๋าสำหรับทั้งห้อง โดย **DM เท่านั้น** ที่เห็นแผง "ล็อก" และกำหนดผลลูกเต๋าของผู้เล่นคนใดคนหนึ่ง (หรือทุกคน รวมถึงตัว DM เอง) ล่วงหน้าได้

## วิธีทำงาน
- ทุกคนกดทอยจากเครื่องทอยของ Extension นี้
- คำขอทอยถูกส่งไปที่เครื่อง DM เครื่อง DM ตัดสินผล (ใช้ล็อกถ้ามี ไม่มีก็สุ่ม) แล้วประกาศผลให้ทุกคน
- ล็อกเก็บใน localStorage ของเบราว์เซอร์ DM เท่านั้น ไม่ถูกส่งไปไหน ผู้เล่นจึงเห็นแค่ผลลัพธ์ปกติ
- ถ้า DM ไม่ออนไลน์ ผู้เล่นจะทอยสุ่มเองหลังรอ 3.5 วินาที
- เมื่อมี DM หลายคน เฉพาะ DM ที่ id น้อยสุดเป็นผู้ตัดสิน และใช้ล็อกของเครื่องนั้น

## ข้อจำกัด
Extension เข้าไปแก้ผลลูกเต๋าที่ติดมากับ Owlbear Rodeo (dice tray ดั้งเดิม) ไม่ได้ ผู้เล่นต้องทอยผ่าน Extension นี้ ล็อกจึงจะมีผล

## ขึ้น GitHub Pages
1. สร้าง repo ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปที่ root
2. ไปที่ Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save
3. รอสักครู่ จะได้ URL เช่น `https://USERNAME.github.io/REPO/`
4. ตรวจว่าเปิด `https://USERNAME.github.io/REPO/manifest.json` ได้

## ติดตั้งใน Owlbear Rodeo
1. ไปที่ Profile → **Add Extension** → ใส่ URL ของ manifest ข้างบน
2. สร้างห้องใหม่ แล้วติ๊กเปิดใช้ Extension นี้ในหน้า Create Room
3. ผู้เล่นทุกคนในห้องต้องเปิดใช้ Extension นี้ด้วย

## ทดสอบบนเครื่อง
```
npx serve --cors .
```
แล้วใช้ `http://localhost:3000/manifest.json` เป็นลิงก์ติดตั้ง
